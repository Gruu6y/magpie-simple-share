开启对外分享 · 使用条款与安全确认

1. 真实密钥绝不离开你的电脑 你的上游 API Key、订阅凭据与 gateway-key 均保存在本机；远端成员只能通过双向公钥认证与 1ms Fail-Closed 校验调用你明确勾选的模型。
2. 请求会经由你的电脑发往上游模型商 模型推理提示词与回复由对方通过端到端加密通道发往你本机的 magpie 执行，消耗你的本机上游额度，日志不记录正文。
3. 个人订阅账号条款与合规风险自担 多数个人订阅类 AI 账号（如 Claude / Codex / Copilot 等）的服务条款限制多人共享或并发复用。请仅限亲友小范围自用，避免同时分享多个并发，并对上游服务条款合规性自行负责。
